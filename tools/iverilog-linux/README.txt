Icarus Verilog 13.0 for Linux x86-64, bundled with SV Studio so Linux users can simulate
without installing anything (useful where you can't use sudo/apt).

Built from the unmodified upstream source, tag v13_0: https://github.com/steveicarus/iverilog/tree/v13_0
on Ubuntu 22.04 (glibc 2.35) with a static C++ runtime, by .github/workflows/build-icarus-linux.yml.
